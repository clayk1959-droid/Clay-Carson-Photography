# Homepage hero — mobile (iPhone) photos

Drop 4–5 JPEGs in this folder and they'll rotate on the homepage hero for
anyone on a phone, fading from one to the next every few seconds. No code
change needed — add, delete, or replace a file here and it takes effect
the next time the site rebuilds (`npm run dev` locally, or the next push
for the live site).

**Crop:** portrait — tall and narrow, like the photo is filling a phone
screen (9:16 works well; 4:5 is fine too if 9:16 crops too tight).

**Export size:** 2600–2800px on the long (vertical) edge, width
proportional to your crop, JPEG quality ~80–85. That's sharp on any phone
screen (including 3x Retina iPhones) without an oversized file.

**Order:** photos rotate in alphabetical order by filename. If you want a
specific order, prefix the filenames: `01-beach.jpg`, `02-porch.jpg`, etc.

These don't need to be the same photos as the desktop folder — pick
whichever crop of a moment looks best in portrait.
